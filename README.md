# Customer Churn Prediction

## Overview
A beginner-friendly end-to-end machine learning project that explores customer churn and compares Logistic Regression with Random Forest.

## Objectives
- Clean and explore IBM's sample telecom churn data.
- Visualize churn patterns by tenure, contract, and internet service.
- Build preprocessing pipelines for numeric and categorical features.
- Evaluate models using accuracy, precision, recall, F1-score, and ROC-AUC.
- Export evaluation charts, feature importance, and a sample high-risk list.

## Dataset
IBM Telco Customer Churn sample dataset:  
https://github.com/IBM/telco-customer-churn-on-icp4d  
Direct CSV: https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

The notebook downloads the dataset automatically when run in an internet-enabled environment. If that fails, download the CSV from the link above and place it beside the notebook.

## Run in Google Colab
1. Upload `Customer_Churn_Prediction.ipynb` to Google Colab.
2. Run the notebook cells from top to bottom.
3. If packages are missing, uncomment the install line in the first code cell.
4. Review the charts and model metrics generated by your own run.
5. Download the `outputs/` files if you want to include them in your portfolio.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Main evaluation metrics
Accuracy, precision, recall, F1-score, ROC-AUC, confusion matrix, and ROC curve.

## Ethical and technical limitations
This is a sample dataset and a learning project. The data is a snapshot rather than a time-series record. Feature importance is not causation. Do not use the model as the sole basis for real customer decisions.
